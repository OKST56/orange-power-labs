PROJECT 01 / ACTIVE DEVELOPMENT

College Baseball Legacy

A long-term vision for college baseball on PC, built on the foundation of MLB The Show 16.

First, bring the game to Windows.

The first challenge is static recompilation: translating the original PS3 executable into code that can run as a native Windows application, supported by a compatible runtime.

The longer-term goal is an NCAA baseball conversion with college programs, conferences, schedules, and a road to Omaha.
